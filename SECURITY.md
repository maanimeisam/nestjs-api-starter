# Security Policy

Report vulnerabilities privately to the repository maintainers rather than through a public issue. Include affected versions, impact, reproduction steps, and any known mitigations. Do not include real credentials or personal data.

Supported deployments should use a maintained Node 24 LTS or a compatible supported release, PostgreSQL 18, strong independent JWT secrets, TLS, restricted CORS origins, and production database credentials. Apply dependency and container updates promptly after testing.
